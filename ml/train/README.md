# Training notes

Recommended student model for the first run:

- `Qwen2.5-VL-3B-Instruct`

Recommended method:

- LoRA or QLoRA supervised fine-tuning;
- train on `../data/dataset/sft_train_final.jsonl`;
- validate on `../data/dataset/sft_val_final.jsonl`;
- test on `../data/dataset/sft_test_final.jsonl`.

## Why SFT rather than logit distillation

The teacher labels are generated by visual teacher annotation and DataLab-assisted silver annotation. No teacher logits are available. Therefore the correct formulation is behavioral distillation / imitation learning via supervised fine-tuning.

## Suggested hyperparameters

These values are a starting point and should be adapted to the actual GPU:

- epochs: 2-4;
- learning rate: `1e-4` for LoRA adapters;
- LoRA rank: 16 or 32;
- LoRA alpha: 32 or 64;
- batch size: as large as memory allows;
- gradient accumulation: enough to reach effective batch size 16-32;
- max image resolution: keep moderate for memory;
- early stopping: based on validation schema validity and block metrics.
